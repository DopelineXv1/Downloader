# Video Downloader Pro

โปรแกรมดาวน์โหลดวิดีโอและเสียงจาก YouTube / TikTok ผ่านลิงก์ ใช้งานง่ายบน Windows พร้อมหน้าจอจัดการคิวดาวน์โหลดและตั้งค่ารูปแบบไฟล์

> **ดาวน์โหลดโปรแกรม:** ไปที่หน้า **[Releases](../../releases)** ของ GitHub แล้วเลือกเวอร์ชันล่าสุด  


## ✨ คุณสมบัติ

- รองรับการดาวน์โหลดจาก YouTube และ TikTok โดยวางลิงก์ลงในโปรแกรม
- เลือกประเภทงานได้ทั้ง **วิดีโอ** และ **เสียงอย่างเดียว**
- เลือกรูปแบบไฟล์วิดีโอ เช่น MP4
- เลือกคุณภาพการดาวน์โหลด เช่น ดีที่สุด
- วางหลายลิงก์เพื่อเพิ่มรายการดาวน์โหลดเป็นคิว
- จัดการรายการในคิว: เริ่มดาวน์โหลด, หยุด, ลองใหม่, ล้างรายการ และล้างรายการที่เสร็จแล้ว
- เลือกโฟลเดอร์ปลายทางและเปิดโฟลเดอร์หลักได้จากโปรแกรม
- ตั้งค่าการแยกโฟลเดอร์อัตโนมัติและรูปแบบชื่อไฟล์
- แสดงสถานะการทำงานและบันทึก Log
- รองรับโหมดมืด / โหมดสว่าง
- ตรวจสอบเครื่องมือที่จำเป็น เช่น `yt-dlp` และ `ffmpeg` พร้อมปุ่มอัปเดต `yt-dlp`

## 📥 วิธีดาวน์โหลดและใช้งาน

### 1. ติดตั้ง Python

โปรแกรมนี้ต้องใช้ Python ในการทำงาน ผู้ใช้งานจำเป็นต้องติดตั้ง Python บนเครื่องก่อน

- ดาวน์โหลด Python ได้ที่ [Python Official Website](https://www.python.org/downloads/)
- แนะนำให้ใช้ Python 3.10 ขึ้นไป
- ขณะติดตั้ง Python บน Windows ให้เลือก **Add Python to PATH**

ตรวจสอบว่า Python ติดตั้งเรียบร้อยแล้ว โดยเปิด Command Prompt (CMD) แล้วพิมพ์คำสั่ง:

```bash
python --version
```

หากแสดงเวอร์ชัน Python แสดงว่าพร้อมใช้งาน

### 2. ติดตั้ง Dependencies

เปิด Command Prompt (CMD) แล้วคัดลอกคำสั่งด้านล่างไปวางเพื่อติดตั้งไลบรารีที่จำเป็น

```bash
python -m pip install --upgrade pip
python -m pip install --upgrade yt-dlp
python -m pip install importlib
python -m pip install importlib-util
python -m pip install dataclasses
```

### 3. ดาวน์โหลดโปรแกรม

1. เปิดหน้า [Releases](../../releases)
2. ดาวน์โหลดไฟล์โปรแกรมจาก Release ล่าสุด
3. แตกไฟล์ ZIP หากไฟล์ที่ดาวน์โหลดเป็น ZIP
4. เปิดไฟล์ `VideoDownloader.exe`

### 4. เริ่มใช้งาน

1. เปิดโปรแกรม Video Downloader Pro
2. วางลิงก์วิดีโอหรือเสียงจาก YouTube / TikTok ในช่องลิงก์
3. เลือกประเภทไฟล์ เช่น วิดีโอ หรือเสียงอย่างเดียว
4. เลือกคุณภาพของไฟล์ที่ต้องการ
5. เลือกโฟลเดอร์ปลายทางสำหรับบันทึกไฟล์
6. กด **เริ่มดาวน์โหลด**
